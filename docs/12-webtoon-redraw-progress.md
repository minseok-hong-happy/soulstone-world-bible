# 웹툰 개편 진행 기록

## 배포 원칙

완성된 회차 묶음마다 원격에 병합하고 GitHub Pages에 반영한다. 새 그림 세 장이 모두 준비된 회차만 개편판으로 전환하고, 나머지는 기존판으로 계속 읽을 수 있게 한다. 부분 제작된 그림도 저장소에 보관하지만 완성 회차처럼 표시하지 않는다.

- 현재 배포 범위와 미제작 이미지: [진행 목록](webtoon-progress.json)
- 확정 캐릭터 참조·컷 구성·생성 프롬프트: [제작 원본](../tools/webtoon-production.cjs)
- 말풍선 화자: [화자 원본](../tools/webtoon-voices.cjs)
- 생성 방식: 내장 이미지 생성 도구. 새 그림 저장 위치는 `site/assets/webtoon-v2/`.

## 반영한 내용

1. 새 그림은 확정 캐릭터 참조를 사용하고, 그림 자체에는 빈 말풍선을 넣지 않는다.
2. 개편판은 18컷을 유지하면서 말풍선을 컷 위 여백에 배치한다.
3. 소설의 구조 이동 시간, 용족과의 대화, 해군전의 인과, 3대 원수전의 잔해 반격을 보완했다.
4. 실검을 심장에 고정한 상태에서는 피얼음 칼날로 싸우도록 연속성을 정리했다.
5. 회차 목록과 독서 화면에서 개편판/기존판을 구분한다.

## 다음 검수와 수정

- 2화 1장: 아버지와 주변 뱀파이어의 얼굴이 겹치는 부분.
- 2화 3장: 또래 뱀파이어의 연령과 머리색 구분.
- 3화 1장, 4화 3장: 젊은 흑발 소장과 적갈색 수염 육군 대장을 구분.
- 5~6화: 새벽 습격의 광원, 목걸이·쌍검 위치와 늑대에 올라타는 순서.
- 7화: 쌍검의 칼집 유지, 추격병이 주요 동료처럼 보이지 않도록 수정.
- 8~9화: 눈 색·소울스톤의 붉은 결 유지와 쌍검을 등에 메는 시점.
- 이후 회차의 확정 캐릭터, 무기, 심장 연결 상태와 장면 순서를 실제 그림에서 계속 검수.
- 후반부 새 전투 컷은 아직 전체 완료가 아니다. 47화 첫 장의 전투 시험 그림을 보관 중이다.

## 중간 배포 절차

1. 새 이미지 제작 및 실제 그림 검수.
2. `tools/webtoon-export.ps1`로 웹용 이미지 반영.
3. `node tools/webtoon-checkpoint.cjs`로 안전한 중간 배포본 생성.
4. `node tools/webtoon-verify.cjs`로 60화 경로와 신·구 독서 화면 검증.
5. 검증한 변경만 원격 main에 반영한 뒤 site 폴더를 gh-pages로 배포.

주의: `webtoon-production.cjs build`는 제작용 전체 초안이다. 미완성 이미지 경로가 포함되므로, 배포 전에는 반드시 checkpoint를 실행한다.
