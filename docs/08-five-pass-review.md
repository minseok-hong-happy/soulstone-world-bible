# 소설 우선 웹페이지 개편 — 5회 검토 기록

## 1차. 세계관 정합성

- 소울스톤은 이마에 존재하는 영혼이며, 죽으면 즉시 별똥별이 되어 임의의 장소에 떨어진다는 규칙을 확인했다.
- 한 사람이 활성화할 수 있는 외부 유물은 하나뿐이고, 일란성 쌍둥이의 쌍검만 같은 파장으로 하나처럼 인식된다는 예외를 유지했다.
- 첫째 형의 등장이 갑작스럽지 않도록 1장에 어린 시절 납치와 늑대의 기억을 복선으로 추가했다. 가족사진 목걸이는 동굴에 남겨지므로 후반 증거에는 가족 관계표와 납치 기록을 사용한다.
- 1대 원수와 2대 원수의 죽음, 3대 원수의 생존과 정전, 성생체의 죽음으로 인한 성 파괴를 정본과 대조했다.

## 2차. 소설 설명과 속도

- 프롤로그에서 탄생·색·유전·죽음·낙하·유물·일곱 가문·독점의 이유를 사건 안에 배치했다.
- 약 1만 자, 11개 장의 완결형 소설로 정리해 전체 줄거리를 15~20분 안에 읽을 수 있게 했다.
- 공개 독서 화면의 편집 메모와 ‘초고’ 표기를 제거해 바로 이야기에 진입하게 했다.
- 동료 모집은 결투의 반복이 아니라 약속, 구조, 해방, 가치 검증으로 차별화했다.
- 정착지와 인간 세 사람의 귀환 사이에 2년의 시간 경과를 명시했다.

## 3차. 정보 구조와 이동 동선

- 첫 화면의 주요 선택을 `소설`, `세계관`, `캐릭터`, `웹툰` 네 개로 제한했다.
- 소설을 첫 번째이자 가장 큰 진입점으로 만들고, 나머지 정보는 상세 자료실 안에서 확장하게 했다.
- 모든 주요 브랜드 링크가 단순 시작 화면으로 돌아가게 통일했다.
- 상세 자료실의 마지막 버튼도 소설을 먼저, 웹툰을 다음에 배치했다.
- 데스크톱 보조 메뉴를 3열로 정렬하고 한글 제목의 음절 단위 줄바꿈을 수정했다.

## 4차. 이미지와 캐릭터 일관성

- 골렘 후보 10안은 모두 세로형 캐릭터 시트, 인간형 돌 생명, 이마의 황금 소울스톤을 공통 기준으로 제작했다.
- 현무암·화강암·대리석·판암·사암·강돌·수정맥·이끼·흑요석·산맥 지층으로 재질과 인상을 분리했다.
- 이미지 10개를 번호가 있는 선택 페이지에 연결하고, 원본을 열어 비교할 수 있게 했다.
- 사용자가 다시 첨부한 어인 참고 이미지를 바탕으로 사람형 얼굴과 비늘·지느러미·푸른 피부를 공유하는 지도자 후보 10안을 제작했다.
- 어인족 지도자는 사용자가 선택한 10번 심연 군주를 정본 캐릭터 이미지에 반영했다.
- 기존 사암 골렘의 미소와 매끈한 얼굴이 느끼하게 보인다는 피드백에 따라 화강암 3안을 만들었으나, 사용자가 전체 후보를 거절했다. 이후 단순한 얼굴 변형 대신 돌 결합 방식과 실루엣을 분리한 신규 후보 10안을 다시 제작했다.

## 5차. 기술·화면 검증

- 로컬 정적 참조 누락: 0개.
- 실제 브라우저 렌더링: 시작 진입점 4개, 세계관 규칙 8개, 캐릭터 33명, 에피소드 60화, 소설 목차 11개가 정상 표시된다.
- 기존 대표 이미지 60개와 웹툰 스트립 360개를 그대로 유지했다.
- 신규 화강암 골렘 후보 10개는 모두 1024×1536 정상 파일이며 공개 선택 페이지에서 열리는 것을 확인했다.
- 사용자가 신규 후보 03 강돌 수호자를 선택했으며, 후보 PNG·JPG와 정본 경로의 SHA-256이 각각 일치함을 확인했다.
- `git diff --check`에서 공백 오류가 없음을 확인했다.

## 확정된 사용자 선택

1. 어인족 지도자는 10번 심연 군주로 확정했다.
2. 골렘 대장은 신규 화강암 후보 03 강돌 수호자로 확정하고 기존 사암 정본을 교체했다.

# 2대 원수·용족 설정 및 신규 후보 50안 — 추가 5회 검토

## 1차. 정본 충돌 검토

- 2대 국가원수의 능력을 타고난 불 소울스톤, 한 자루의 칼, 세계 최상위 검술로 통일했다.
- 과거의 용 유물 설정은 정본에서 제외하고, 과거 이미지 문서에는 폐기 시안임을 명시했다.
- 여행 동료를 혼혈이 아닌 순수 용족으로 바꾸고 세계관, 캐릭터, 세력, 소설, 60화 전개에 함께 반영했다.
- 해군 대장 기존 06안 확정을 철회한 뒤 신규 01 흑발 젊은 제독을 정본으로 확정했다.

## 2차. 이야기 기능 검토

- 26화는 혼혈끼리의 거울 구조 대신, 중립이 방관이 되었는지 묻는 순수 용족의 선택으로 재구성했다.
- 49화는 용 유물의 출처 폭로를 반복하지 않고 2대 원수의 단 한 번의 불검으로 전선이 멈추는 등장으로 바꿨다.
- 51화는 거대 속성전이 아니라 불과 얼음을 보법과 검로에 압축한 두 세계 최고 검객의 결투로 바꿨다.
- 2대 원수와 1대 원수가 서로 치명상을 입는 결말, 3대 원수의 생존과 정전은 그대로 유지했다.

## 3차. 후보 차별화 검토

- 다섯 인물군마다 머리, 연령, 체형, 의상, 무기 실루엣을 달리한 10안을 제작했다.
- 2대 원수 후보에는 용의 뿔·비늘·날개를 넣지 않았고, 모두 한 자루의 칼과 불 소울스톤을 유지했다.
- 육군 1번대 중장은 여러 독립 무기가 아니라 한 자루의 큰 칼이 분할되는 능력으로 통일하고, 신규 10 흉터 중장갑 대장을 외형 정본으로 확정했다.
- 첫째 형은 신규 09 회색 장발 실험체를 정본으로 확정하고, 부분 적응 장갑과 소울스톤 통제 장치를 유지했다.
- 해군 대장은 신규 01 흑발 젊은 제독을 정본으로 확정하고, 물·얼음과 혼동되지 않도록 모든 능력 효과를 반사광이 있는 강철로 표현했다.

## 4차. 페이지 사용성 검토

- 정본 캐릭터 페이지와 선택 전 후보 페이지를 분리했다.
- 후보 페이지에 다섯 인물 바로가기, 01~10 번호, 큰 이미지 확대 창과 모바일 2열 배치를 넣었다.
- 캐릭터 페이지에는 상단의 `신규 후보 50안 보기` 버튼만 추가해 기존 단순한 진입 구조를 유지했다.
- 사용자가 `2대 원수 3번, 3대 원수 7번`과 같은 형식으로 바로 선택할 수 있게 안내했다.

## 5차. 파일·코드 검토

- 후보 JPEG 50개가 다섯 폴더에 정확히 10개씩 존재하며 로컬 HTTP에서 모두 200 응답을 반환했다.
- 원본 112MB를 웹용 고화질 JPEG 약 19MB로 최적화했다.
- JavaScript 구문, `git diff --check`, 60화·360개 웹툰 스트립 참조를 검사했으며 누락은 0개다.
- 브라우저 연결 기능은 현재 사용할 수 없어 자동 화면 캡처 검수는 수행하지 못했고, 로컬 HTTP·DOM 구조·반응형 CSS·파일 참조 검증으로 대체했다.
