## 현재 확정된 이야기의 중심

인간과 괴물이 함께 살던 세계에서 인간 연합의 장로회가 소울스톤을 독점하기 위해 괴물을 학살하고 거대한 성을 세운다. 인간과 뱀파이어 사이에서 태어난 주인공은 가족을 잃고 복수의 길에 오르지만, 인간인 어머니의 유언과 여행에서 만난 사람들을 통해 목표를 바꾼다. 최종 목표는 인간을 몰살하는 것이 아니라 학살을 만든 체제와 성벽을 무너뜨리고, 인간과 괴물이 다시 함께 사는 세계를 만드는 것이다.
