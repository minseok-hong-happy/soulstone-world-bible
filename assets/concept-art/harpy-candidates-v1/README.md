# 하피족 지도자 후보 10안

## 공통 규칙

- 매력적인 성인 인간형 얼굴과 몸, 등에서 돋은 한 쌍의 큰 날개, 깃털 귀·팔·종아리, 맹금류형 발을 사용한다.
- 날개가 팔을 대신하지 않으며 추가 날개를 만들지 않는다.
- 이마 중앙에 소울스톤을 두고 실전 비행에 적합한 비노출형 복장을 사용한다.
- 극사실주의, 공포물, SD, 글자, 로고, 워터마크를 사용하지 않는다.

## 후보

1. 황금독수리 공중대장 — 창과 지휘력에 집중한 정통 전사형.
2. 송골매 바람정찰자 — 고속 정찰과 쌍단검을 쓰는 기동형.
3. 흰올빼미 별길잡이 — 밤하늘과 기류를 읽는 지적인 예언자형.
4. 까마귀 폭풍전술가 — 활과 전술 판단에 집중한 냉정한 지휘관형.
5. 붉은솔개 구조대장 — 구조 장비와 갈고리로 동료를 구하는 친근한 행동대장형.
6. 수염수리 산맥족장 — 거대한 장병기와 강한 체격을 지닌 최고 전사형.
7. 물총새 하늘전령 — 선명한 색과 뛰어난 속도를 지닌 연락·운송형.
8. 알바트로스 장거리길잡이 — 폭넓은 날개와 침착함을 지닌 원정대장형.
9. 두루미 하늘치유사 — 야전 치료와 구조를 함께 맡는 우아한 치유사형.
10. 매 부족장 — 구조대장의 온기와 전사의 권위를 절충한 정본 지향형.
