# 화강암 골렘 대장 신규 후보 10안 — 3번 선택 완료

이전 3안이 같은 보디빌더형 체격과 비슷한 얼굴에 머물렀던 문제를 보완했다. 회색 화강암, 이마의 황금 소울스톤, 우직한 지도자라는 공통점만 남기고 돌의 결합 방식과 전체 실루엣을 구분했다.

1. [블록 파수꾼](golem-01-block-watchman.png) — 각진 석판과 정직한 얼굴의 기본 수호자형.
2. [능선 대장](golem-02-crown-ridge-captain.png) — 머리와 등에 짧은 능선이 이어지는 지휘관형.
3. **[강돌 수호자](golem-03-river-stone-protector.png) — 최종 선택.** 물에 닳은 둥근 화강암과 친근한 인상의 방어형.
4. [모놀리스 수도자](golem-04-monolith-monk.png) — 긴 수직 석판과 최소한의 얼굴을 지닌 장신형.
5. [성벽 감시자](golem-05-fortress-warden.png) — 하나의 성벽 같은 몸통과 방패형 팔의 방어 특화형.
6. [채석장 정찰대장](golem-06-quarry-ranger.png) — 좁은 몸통과 긴 팔다리를 지닌 최고 기동형.
7. [고대 관문 수호자](golem-07-ancient-gate-guardian.png) — 풍화된 수호상과 지층을 살린 정통 중량형.
8. [석영맥 수호자](golem-08-quartz-vein-keeper.png) — 화강암 사이의 유백색 석영이 특징인 균형형.
9. [살아 있는 산](golem-09-living-mountain-gardener.png) — 돌 틈의 풀과 꽃이 자연 생명임을 보여주는 공생형.
10. [균형형 공동체장](golem-10-balanced-clan-leader.png) — 체격·기동성·지도자 실루엣의 중간값을 지향한 정본형.

이미지는 내장 이미지 생성 기능으로 후보별 한 번씩 제작했다. 선택본은 `../anime-v4/07-golem-leader-anime-v4.png` 정본 경로에 반영했다.
