# 여성 거미인간 대장 후보 10안

곤충·절지 종족 연합을 이끄는 여성 거미인간 대장 후보군이다. 사용자 선택 결과 **09 백색동굴거미 청망자**를 최종 정본으로 반영했다.

## 공통 규칙

- 매력적인 성인 여성 인간형 얼굴과 몸, 일반적인 두 팔과 두 다리를 유지한다.
- 등에는 자연 갑각으로 된 보조 거미다리 정확히 네 개를 둔다. 거대한 거미 배·거미 하반신·추가 인간 팔은 사용하지 않는다.
- 관자놀이 주변의 작은 보조안, 이마 중앙의 소울스톤, 실을 다루는 행동으로 종족을 표현한다.
- 실전적인 비노출형 복장과 현대 TV 애니메이션풍 셀 채색을 사용한다.
- 공포물, 고어, 성적 강조, 기계 다리, 글자, 로고, 워터마크를 사용하지 않는다.

## 후보

1. 황금무당거미 전략가 — 황금 전술망을 짜는 침착한 총지휘관형.
2. 붉은과부거미 잠입자 — 붉은 실과 단검을 쓰는 은밀한 첩보형.
3. 은빛실 기술자 — 실 교량과 방어 구조물을 만드는 공병형.
4. 에메랄드 깡충거미 정찰자 — 뛰어난 도약과 관찰력을 지닌 기동형.
5. 갈색농발거미 수호자 — 넓은 보조다리와 실 방패로 동료를 지키는 방어형.
6. 공작거미 환영술사 — 유색 실의 무늬와 잔상으로 적을 속이는 교란형.
7. 문거미 보루대장 — 지면에 실을 고정해 함정과 방어진지를 만드는 요새형.
8. 타란툴라 전선수호자 — 굵은 구조용 실로 전우를 끌어내는 강인한 보호자형.
9. 백색동굴거미 청망자 — 감각실의 진동으로 먼 움직임을 듣는 탐지형.
10. 보랏빛 거미여왕 — 지휘봉과 거대한 실망을 사용하는 균형 잡힌 정본 지향형.

원본은 내장 이미지 생성 기능을 후보별로 한 번씩 사용해 제작했다.
