# 화강암 골렘 대장 재수정 후보 3안 — 폐기

기존 사암 수도자형 골렘의 느끼한 미소와 매끈한 인간형 얼굴을 제거하고, 회색 화강암 재질과 약 10~15% 절제된 체형을 공통 기준으로 다시 제작했다.

1. [우직한 파수꾼](golem-granite-01-honest-sentinel.png) — 곧은 눈썹과 정직한 눈, 다문 입을 지닌 듬직한 수호자.
2. [젊은 장군](golem-granite-02-young-commander.png) — 세 후보 중 가장 절제된 체형과 전투적인 지휘관 인상.
3. [산의 수도자](golem-granite-03-mountain-monk.png) — 거친 돌결과 차분한 눈을 지닌 말수 적은 수호자.

세 후보 모두 이마의 황금 소울스톤, 얇은 황금 에너지 균열, 인간형 골렘 구조와 현대 애니메이션 셀 채색을 공유한다. 최종 선택 전에는 기존 `anime-v4/07-golem-leader-anime-v4.png` 정본을 덮어쓰지 않는다.

사용자 검토 결과 세 후보 모두 채택하지 않았다. 새 선택지는 [`golem-granite-candidates-v3`](../golem-granite-candidates-v3/README.md)에서 관리한다.
