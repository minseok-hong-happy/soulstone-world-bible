# 어인족 지도자 후보 10안 — 10번 선택 완료

사용자 참고 이미지의 푸른 피부, 얼굴 비늘, 지느러미 귀, 물결 같은 머리카락과 장신구를 종족 공통 특징으로 삼았다. 반인반수 지도자 이미지의 캐주얼 현대 애니메이션 선화와 셀 채색을 화풍 기준으로 사용했다.

1. [심해 파수꾼](merfolk-01-deep-sea-sentinel.png) — 정통 심해 지도자와 삼지창.
2. [해류 검사](merfolk-02-tide-swordsman.png) — 가볍고 빠른 해안 검사.
3. [진주 예언자](merfolk-03-pearl-oracle.png) — 진주 장신구와 의식용 지팡이.
4. [상어 혈통 지휘관](merfolk-04-shark-commander.png) — 강한 체격의 전면 전투 지휘관.
5. [산호 왕자](merfolk-05-coral-prince.png) — 산호색 왕족 복식과 외교적 인상.
6. [가오리 수호자](merfolk-06-manta-warden.png) — 가오리 망토와 쌍검.
7. [발광 정찰대장](merfolk-07-bioluminescent-scout.png) — 생체 발광과 구조·탐색 능력.
8. [해룡 장군](merfolk-08-sea-dragon-general.png) — 비늘 갑주와 장병기.
9. [산호초 치유자](merfolk-09-reef-healer.png) — 생명 보호와 치유를 앞세운 지도자.
10. **[심연 군주](merfolk-10-abyss-sovereign.png) — 최종 선택.** 가장 장엄하고 강한 최고 지도자형.

모든 후보는 이마 중앙에 소울스톤을 지니며, 어인족은 인간 해군의 강제 채집에서 해방된 뒤 바다의 지역 동맹으로 남는다는 세계관을 공유한다.

선택본은 `../important-characters-v1/16-merfolk-leader.png` 정본 경로에도 반영했다.
